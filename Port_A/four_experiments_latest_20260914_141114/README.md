# 四组实验最新数据、程序和结果归档

## 目录
- shared_data：63例共享CT、上游参考掩膜，以及实际计算使用的拆分病灶掩膜。不重复复制大文件。
- 01_task_execution：原题中存在性/计数/肝脏体积最新结果102题，体积最新重测27题，标准化直径25题，共154题。
- 02_multi_case_management：最新63组双病例比较结果、配对问题与测试程序。
- 03_evidence_faithfulness：最新137题病例缺失测试结果；使用不存在的病例标识，不需要创建或删除影像。
- 04_cache_efficiency：最新137题缓存测试及同批137题首次计算记录。
- provenance/formal_batch：原批次完整记录、几何核验及运行参数，保留来源。
- source_snapshot_current：整理时源码快照，不代表每个历史批次执行时的逐字源码版本。
- documentation_and_preparation：数据准备程序、逐题体积复核及修复说明。
- copied_files_sha256.json：所有复制文件的来源、大小和SHA-256；已逐文件验证副本与原件一致。

## 复现边界
tests中的程序按原样保存，部分使用E盘绝对路径及原项目/.env配置。该归档用于证据汇总，不是双击即运行的软件安装包。
重跑前需将程序的数据路径指向shared_data、配置Port A模型与真实Port B服务，并按原准备流程注册病例。
模型凭据、.env、虚拟环境及模型权重不包含在归档中。不能将当前源码快照称为全部历史批次的精确版本。
双病例参考答案由几何审计中的肝脏体积决定；配对顺序与原评测代码一致。
