# 病灶体积修复与原题重测

原27题、15例，使用既有参考掩膜，经Port A调用真实HTTP Port B执行计算。保持原题、原VQA答案和原评分容差，另检查回答是否等于完整工具总体积。旧结果未改写。

## 原因与修复

1. Port A只展示前10个病灶，且未提供全部病灶总体积。Port B新增总体积、最大单病灶体积、覆盖病灶数量及范围字段，skill入口传递这些字段，Port A在截断详情前显示汇总。
2. 提示词允许“计算总和或报告最大的”，导致测量对象混淆。现在未指定单个或最大病灶时使用总体积，禁止部分和替代总体积。
3. 每个病灶先保留两位小数再求和带来累积舍入。新增未舍入体积供汇总，最后统一保留两位小数。
4. 直径几何异常原先中断整个分析。现在直径异常单独记录为null及失败说明，保留体积。故障注入验证通过。
