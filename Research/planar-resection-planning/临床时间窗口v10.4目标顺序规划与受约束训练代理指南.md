## 0. 代理必须先读

**禁止直接复制 v9/v10.1 的 target-PPO 重跑。**本轮首先用与最终评价一致的规划器证明
“固定 15/5 下优化宏目标顺序”确实存在可学习收益。规划器不过门就停止，不用 reward
调参或 Optuna 掩盖任务本身缺少优化空间的事实。

## 1. 决策与历史证据

### 1.1 保留的方向

- 高层策略只选择下一个合法前沿目标格。
- 底层沿已切区域执行确定性最短路转移。
- 转移逐格计入时间，开放期同时计入模拟失血。
- 全程使用机械 15 min 夹闭 / 5 min 开放。
- `END` 全程 mask，不允许提前松夹。
- baseline 是机械 S 形 + 相同 15/5 状态机 + 相同底层转移器。

### 1.2 为什么不能原样重跑

v9 Stage 1B 已做过近似实验：固定 15/5，高层 PPO 选宏目标，底层自动转移。它的早期候选
仅平均减少 4.66 mL 失血，同时增加 0.37 min；配对 bootstrap 95% CI 不能证明双指标改善。
后期候选呈现“更长路线换更少失血”的权衡，但耗时显著恶化。v10.1 在统一纯 Stage-D 分布上
重训后，唯一通过失血安全门的 checkpoint 仍接近 BC 初始点，PPO 后续普遍恶化。

因此 v10.4 必须新增：

1. 训练前的真实路线级别强规划器机会 Gate；
2. 能比较所有合法候选的全局候选打分器，取代仅看局部邻域的旧 target head。

### 1.3 已停止的路线

- v10.3 “前瞻特征 -> 提前松夹安全分类” Pilot 已 FAIL，不得复活。
- 不得放宽 `unsafe-FPR <= 5%` 让旧 clamp 分类器通过。
- 不得解锁 threshold-10、threshold-5 或 full END。

## 2. 预先冻结的研究问题

> **在完成率和合法性全部通过、且预期模拟失血量相对 S 形 baseline 满足非劣效性的模型中，
> 选择平均总耗时最短者。**

代理不得在看到结果后改成“失血优先”。如将来要改成“耗时不增加超过 1% 时尽量减少失血”，
必须在新实验开始前另行冻结，不能由 Optuna 或 checkpoint 结果反向决定。

### 2.1 硬约束

| 项目 | 要求 |
| --- | ---: |
| episode 完成率 | 100% |
| 合法动作率 | 100% |
| `END` 次数 | 0 |
| 停滞/循环/超时失败 | 0 |
| 失血非劣界值 | $M_B=0.05\,\overline B_{\mathrm{baseline}}$ |
| 失血安全门 | $CI_{95\%,upper}(\Delta B)\le M_B$ |

其中 $\Delta B=B_{candidate}-B_{baseline}$，$\Delta T=T_{candidate}-T_{baseline}$。统计使用按 scene
配对的 bootstrap，不得把同 scene 内状态当作独立样本。

### 2.2 最终选择顺序

1. 硬约束是否全部通过；
2. 平均 $\Delta T$ 最小；
3. 平均 $\Delta B$ 最小；
4. transfer count/overhead 最小；
5. 张力辅助审计更好。

shaped return、BC loss 和 Optuna trial value 都不得越过这个顺序。

## 3. 不可变更的模拟假设

- 夹闭最长 15 min，开放期固定 5 min，两者到时自动切换。
- 本轮 `early_end_mode=disabled`。
- 单格为边长 4 mm 的正方形，面积 16 mm²。
- 模拟失血与暴露血管截面面积和统一概率系数有关，单位为 mL。
- 夹闭期、未暴露或已经超声刀切断封闭的血管不出血。
- 大于 1 格的血管分量为大血管，处理时间为普通血管的 3 倍。
- time/blood scales 只在 Train 上计算一次，随后冻结。
- baseline 和学习策略必须共享完全相同的转移、时间、失血和时相积分代码。

报告中必须写“预期模拟失血量”，不得宣称是真实术中失血量。

## 6. Gate A：先用强规划器证明目标顺序存在可利用机会

### 6.1 公平对照

每个 scene 使用同一环境配置分别 rollout：

1. `serpentine_fixed15_5`；
2. `nearest_frontier_fixed15_5`；
3. `window_aware_planner_fixed15_5`。

三者共享 action mask、底层最短路、转移计费、切割时长、失血积分和 15/5 状态机。

### 6.2 规划器选择规则

每个候选分支克隆当前环境，执行真实宏动作，再用冻结 S 形 tail 完成剩余 episode，得到同一
口径的最终 $T$ 和 $B$。规划器按以下顺序选分支：

1. 能完成且动作全部合法；
2. 预计失血不超过同 scene S 形 baseline $B_{base}+M_B$；
3. 预计总耗时最短；
4. 失血更少；
5. transfer 更少。

如 beam 内没有可行分支，必须回退到当前状态的 S 形下一动作，不得选已知超过失血约束的分支。

### 6.3 有限前瞻参考实现

- 从合法前沿中构造候选并集：最近、可封闭血管、高暴露风险和低转移目标。
- 剪枝上限、beam width 和前瞻深度只能在 `planner_tune` 调整。
- 起始建议：候选 8--12，beam width 32--64，前瞻 16--32 个宏动作；每个叶节用完整 S 形
  tail 计算 episode 结局。
- 采用 receding-horizon：只执行当前搜索选出的第一个目标，到新状态后重新规划。
- 缓存重复 state/tail，报告单 scene 耗时、候选数、展开节点数和 cache hit rate。
- 先做 8 scene smoke，再做 32 scene 资源 Pilot。单 scene 中位耗时超过 10 min 时必须先优化或减小
  搜索，禁止直接扩展到 128 scene。

### 6.4 Gate A GO/NO-GO

`planner_gate` 128 场景必须同时满足：

| 指标 | GO 条件 |
| --- | ---: |
| planner/baseline 完成率 | 128/128 |
| 合法动作率 | 1.0 |
| END/停滞/循环/failure | 全部 0 |
| 失血安全 | $CI_{upper}(\Delta B)\le M_B$ |
| 耗时优效 | $CI_{upper}(\Delta T)<0$ |
| 耗时效应量 | $\overline{\Delta T}\le-0.005\,\overline T_{base}$ |

任一不满足即 **Gate A NO-GO**：禁止构建正式 v10.4 数据、BC、DAgger、PPO 和 Optuna；
输出负面结果报告和 Pareto 图。结论应写为“在当前模拟器和总耗时主终点下，未证明
目标顺序学习存在足够收益”。

## 7. Gate B：全局候选策略与教师学习

仅在 Gate A GO 后执行。

### 7.1 每个合法目标的显式特征

特征只能来自当前可观测状态和确定性下一宏动作，不能直接泄漏 teacher 最终 cost 或标签。
至少包含：

- 最短转移格数、转移时间和目标切割时间；
- 是否为大血管、血管格数和面积；
- 预计到达/完成时相、距下一时相边界时间；
- 转移或切割是否跨越 15/5 边界；
- 下一宏动作的精确 $\Delta T$、$\Delta B$；
- 新暴露/新封闭血管面积、操作后未封闭总面积和出血率；
- 当前位置、全局切除比例和 transfer overhead。

连续特征 scales 只在 Train 上计算并冻结。

### 7.2 策略架构

禁止继续使用仅靠局部卷积对每格独立打分的旧 `SpatialActionHead`。推荐最小架构：

```text
网格观测 -> 共享空间编码器 -> frontier 局部 embedding -----+
候选显式特征 -> candidate MLP ---------------------------+
frontier/domain-mask 全局 mean/max pooling + 时相标量 -------+
                                                              v
                                             共享 scorer -> candidate logits
```

要求：

- scorer 在所有格共享权重；
- 同时计算 `frontier` masked context 和 `domain/valid` masked scene context：前者用于比较当前候选，
  后者保留尚未到达前沿的剩余组织/血管信息；
- 两种 global pooling 都必须使用真实 mask，不能被 padded 空白格稀释；
- 空间编码器需通过更深/膨胀卷积或其他尺寸保持方法扩大有效感受野；不得原样复用旧的局部
  3x3 scorer 并只更换类名；
- action mask 仍由环境保证；
- 初版不强制 Transformer/LSTM；全局候选上下文已是必要架构改动；
- critic 可看全局编码，但不得向 actor 泄漏 teacher cost-to-go。

### 7.3 张力处理

现有 `mechanics_update_interval=0` 会把张力全部置零，不是每步求解。v10.4 主训练不对未标定张力
加 reward：

```text
front_tension_cost = 0
organ_energy_cost = 0
vessel_strain_cost = 0
```

主策略始终对 `front_tension/organ_energy/vessel_strain` 三个通道使用冻结零 mask，避免训练/评估
观测分布改变。但在 baseline、Validation、Test 和 Stress 的最终轨迹上，必须用
`mechanics_update_interval=1` 独立 replay，报告峰值/均值张力、器官能量和血管应变。

这表示“张力仍被模拟和评估，但本轮不是主优化目标”。张力 replay 不得改变策略动作、
总耗时或总失血。

### 7.4 BC 与最多一轮 DAgger

- teacher 保留完整候选 ranking/cost difference，不只保留 top-1 class。
- 首先用 pairwise ranking loss 或 listwise cross-entropy 训练。
- 报告 top-1、top-3、NDCG，但准入以真实 rollout 为准。
- 若 BC 不过 Gate B，允许在 Train 做一轮 DAgger，补充模型实际访问状态的 teacher ranking，然后
  从原 BC checkpoint 重训。
- DAgger 后仍不过则 NO-GO，禁止用 PPO “拯救”未能复现 teacher 的模型。

### 7.5 Gate B GO/NO-GO

在冻结的 Train-internal dev scene 上确定性 rollout，必须：

- 完成率/合法率 100%，END/failure 0；
- $CI_{upper}(\Delta B)\le M_B$；
- $CI_{upper}(\Delta T)<0$；
- 实际耗时收益至少保留 teacher 收益的 50%：

$$
R_T=\frac{\overline T_{base}-\overline T_{model}}
{\overline T_{base}-\overline T_{teacher}}\ge0.50.
$$

如分母小于 baseline 耗时的 0.5%，视为 Gate A 效应量不足，不得用不稳定的比值进入 PPO。

## 8. Gate C：受约束 PPO Pilot

仅在 Gate B GO 后执行。

### 8.1 奖励

$$
r_t=-\frac{\Delta T_t}{T_{scale}}
-\lambda_B\frac{\Delta B_t}{B_{scale}}.
$$

配置必须满足：

```text
progress_bonus = 0
seal_progress_bonus = 0
front_tension_cost = 0
organ_energy_cost = 0
vessel_strain_cost = 0
completion_bonus = 5
failure_penalty >= 10
invalid_action_penalty >= 10
early_end_mode = disabled
```

- transfer 时间已包含在 $\Delta T_t$，禁止加独立 transfer penalty。
- 如保留 `clinical_cost_cap`，必须证明 Train/Tuning 的成功 episode 均未触发饱和。
- 优化目标是未折扣的 episode 总时间/失血，首选 `gamma=1.0`。如数值不稳定需改用 `gamma<1`，
  必须测试延后成本偏差，且不得低于 0.9999。
- 每个 checkpoint 用原始 min/mL 审计；reward 只用于梯度。

### 8.2 Pilot 范围与 Gate

- 从 Gate B 最佳 BC/DAgger checkpoint 初始化；
- 单 seed，20k--30k steps；
- 学习率从 $10^{-5}$--$5\times10^{-5}$ 开始；
- 监控相对初始策略的 KL 并 early stop；
- 至少每 5k steps 在 Train-internal dev 确定性 rollout；
- 失血安全门失败的 checkpoint 不得被“reward 更高”覆盖。

Gate C GO 要求：至少一个 PPO checkpoint 在所有硬约束通过时，平均耗时优于 Gate B 初始策略。
否则停止 PPO，保留 BC/DAgger 为当前最佳，禁止 Optuna。

## 9. Optuna 与正式评估

仅在 Gate C GO 后启动。Optuna 不用来决定“时间和失血哪个更重要”，而是在约束已冻结后寻找
训练配置。

### 9.1 可搜索项

- `learning_rate`、`n_epochs`、`batch_size`；
- `gae_lambda`、`ent_coef`、`clip_range`、`target_kl`；
- 有界的 $\lambda_B$。

网络架构和宽度必须在 Gate B 前冻结，不得在 PPO Optuna trial 中更换；否则不能从同一个
Gate B checkpoint 公平初始化。

禁止在 trial 中改数据、失血模型、血管时间倍数、时间状态机或非劣界值。

### 9.2 约束目标

每个 trial 在 Tuning-64 上返回：

- 主目标：最小化 $\overline{\Delta T}$；
- 约束 1：完成率、合法率、END 和 failure；
- 约束 2：$CI_{upper}(\Delta B)-M_B\le0$。

推荐 Optuna constrained sampler，或先排除不可行 trial、再比较耗时。禁止将时间、失血和 transfer
任意相加成可事后调整的分数。

初次上限 24 trials。取最多 3 个可行候选，每个使用 3 个预先固定的 seed 从同一 Gate B checkpoint
重训，在 Validation-128 确认。按第 2.2 节冻结唯一候选后，Test-128 和 Stress-128 各评估一次。
Test 失败后不得调参再测同一 Test。

## 10. 必须通过的行为测试

Gate A 前至少新增：

1. 固定 15/5 在转移/切割跨边界时积分精确。
2. `END` 在所有 v10.4 状态均为 illegal。
3. 合法宏目标每步产生新切除，无低层循环。
4. 候选预测的转移数、$\Delta T$、$\Delta B$ 与克隆环境真实 `step()` 一致。
5. 大血管处理时间恰为普通血管的 3 倍。
6. 夹闭期、未暴露和已封闭血管失血增量为 0。
7. transfer 只通过时间成本出现一次。
8. `progress_bonus=seal_progress_bonus=0` 时没有隐含顺序塑形。
9. `mechanics_update_interval=0` 置零，`=1` 在非平凡场景产生有限可重复指标。
10. 张力 replay 不改变动作、总耗时或总失血。
11. frontier/domain-masked global pooling 不被 padded 区域改变。
12. 局部邻域相同、全局前沿/时相不同的状态可产生不同 logit。
13. 非法格在 deterministic/stochastic 评估都不可被采样。
14. 所有 split ID、seed 和 hash 无交叉。
15. bootstrap 以 scene 为单位并用配对差值。

任一失败时禁止开始 Gate A 或训练。不得通过删测试、放宽容差或只测 happy path 解决失败。

## 13. 强制停止条件

出现任一情况必须停止当前路线并报告：

1. Gate A 无法在失血非劣下证明耗时优效。
2. 规划收益小于 baseline 耗时的 0.5%。
3. BC + 最多一轮 DAgger 仍无法保留 50% teacher 耗时收益。
4. 任一策略以降低完成率、非法动作或超时截断换取低耗时/低失血。
5. PPO Pilot 没有任一 checkpoint 在安全可行前提下优于 BC/DAgger。
6. 出现明显 split 分布错配。
7. 事后改非劣界、主终点或 checkpoint 选择顺序。
8. Test 一次性评估失败。

“还可以继续调参”不是跳过停止条件的理由。
