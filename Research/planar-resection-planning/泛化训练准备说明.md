# Spatial-v3 7×7 自定义血管泛化训练准备

## 当前能力

- 模拟器默认 ML 策略为 `toy7_vessel_spatial_v3`。
- 策略输入为 17 通道局部 7×7 网格，动作数为 49。
- API 和界面允许 7×7 连通域中的自定义内部血管布局；起点必须位于域边界且不能与血管重叠。
- v3 仍是研究模拟器策略，不代表临床安全性结论。

## 训练分布

训练场景生成器 `generate_training_scenarios` 已覆盖 8 类布局：平移单血管、紧凑单/多细胞血管、不规则域、多个血管、大血管和凹形域。所有场景保持 7×7 网格，但血管位置、数量和域形状随机变化。

建议下一轮使用 128 或 256 个固定随机场景，并保存 seed；训练前先检查类别计数、血管均为内部单元、域连通且起点合法。

## 推荐启动命令

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 \
MPLCONFIGDIR=/tmp/mpl_codex PYTHONUNBUFFERED=1 \
python -u train_spatial_masked_ppo.py \
  --output-dir results/ppo_spatial_v3_generalization_seed2026073001_25k \
  --timesteps 25000 --n-envs 8 --train-scenarios 128 \
  --bc-epochs 20 --learning-rate 1e-5 --n-epochs 3 --target-kl 0.01 \
  --transfer-cost 2.0 --teacher-planner-fraction 0.25 \
  --seed 2026073001 --device auto
```

25k 只用于早期筛选；候选模型必须继续通过固定的 120 Test + 80 Stress 评估，才考虑 100k 训练或替换部署模型。选择标准是完成率、合法率、释放规则全部通过，并且 Test/Stress transfer 不劣于当前 v3 基线。
