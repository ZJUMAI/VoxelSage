## 2. 研究问题和边界

研究对象是：在已经确定的肝脏手术剖面上，将目标区域离散为网格单元，从合法起点出发，
选择一系列切除单元，最终覆盖全部目标区域。

当前研究只负责“单元级序贯选择和覆盖顺序”，不负责：

- 连续刀具轨迹、速度和姿态；
- 真实器械可达性和碰撞检测；
- 临床定量应力或撕裂概率预测；
- 自动选择最佳手术剖面；
- 直接从真实病例学习医生操作策略。

整体路线为：

```text
CT 分割与三维重建
  → 用户确认手术剖面
  → 曲面或平面网格化
  → 序贯切除决策
  → 路径播放与指标评价
  → 通过二维验证后再迁移曲面图
```

## 4. 当前环境定义

### 4.1 一个 episode

每个随机切面、血管布局和合法起点构成一个 episode。episode 从未切状态开始，直到：

- 全部目标格完成切除，成功结束；
- 没有合法动作但仍有未切目标，失败结束；
- 达到最大步数，截断结束。

模型不把每一次 transfer 当作 RL 动作。RL 只选择“下一个想切的前沿格”，环境自动计算
从当前位置经过已切区域到达该格所需的 transfer，并随后执行一次 cut。

### 4.2 状态 observation

第一版使用固定大小的二维多通道张量，建议统一为 `50 × 50 × C`，不足部分使用 mask
填充。至少包含：

| 通道 | 内容 |
| --- | --- |
| domain | 是否属于切面域 |
| cut | 是否已经切除 |
| vessel | 当前有效血管格 |
| released_vessel | 已游离血管格 |
| frontier | 当前合法切除前沿 |
| current_position | 当前工具位置 |
| start | 起点 |
| thickness | 2.5D 厚度场 |
| normal_tension | 法向张力 |
| shear_tension | 剪切张力 |
| front_tension | 切口前沿综合张力 |
| organ_energy | 器官局部应变能 |
| vessel_strain | 血管连接应变 |
| tip | 切口尖端标记 |
| valid_cell_mask | 网格有效区域 |

所有连续力学量必须使用训练集统计量或固定物理范围归一化；不能每个 episode 单独按
当前最大值归一化，否则模型会失去跨场景比较能力。

### 4.3 动作和 mask

动作是固定大小动作空间中的一个格子编号，最大为 `50 × 50 = 2500`。合法动作 mask
只允许当前未切、非血管且属于动态前沿的格子。

动作 mask 负责硬约束，不用负奖励教模型学习基本规则。环境必须在 mask 之外再次校验，
防止训练脚本或推理脚本绕过约束。

### 4.4 状态转移

一次 `step(action)` 执行：

```text
检查动作是否合法
  → 在已切区域内搜索当前位置到目标前沿的最短 transfer
  → 记录 transfer 事件
  → 执行目标格 cut
  → 更新有效血管和 release 状态
  → 重新计算 2.5D 力学状态
  → 更新 frontier、mask、指标和终止状态
```

环境必须返回事件序列，至少包含 `transfer`、`cut`、`release` 和失败原因，便于和现有
规划器逐项对照。

## 5. 2.5D 张力状态

每个二维格对应上下两个三维组织节点。切除时断开该格的上下跨平面连接，并删除会桥接
已打开切面的跨表面连接；上下表面节点和表面内连接保留。

当前力学模型使用：

- 外围软支撑；
- 法向初始预应变；
- 平面内初始残余应变；
- 上下表面平面内连接；
- 跨表面斜向连接；
- 血管和器官—血管连接刚度差异。

没有用户 Anchor/Pull 时仍然可以计算张力。若法向和表面内预应变都设为 0，模型应返回
零张力，这是回归测试的一部分。

切口前沿记为：

$$
\Gamma_t=\{q\notin C_t\mid N_4(q)\cap C_t\neq\varnothing\}.
$$

前沿综合牵引为：

$$
T_{\mathrm{front}}(q)=
\sqrt{T_n(q)^2+T_s(q)^2+T_{\mathrm{interface}}(q)^2}.
$$

这些量用于状态和评价，不直接解释为临床应力单位。

## 6. 规则基线

机器学习之前必须冻结至少三类基线：

1. 外向内、逐行切除 baseline；
2. 当前动态前沿规则规划器；
3. 历史固定权重 Pilot 的最佳可复现结果。

规则基线的作用不是证明规则算法最终正确，而是：

- 验证环境事件语义；
- 提供 RL 的最低比较标准；
- 检查奖励函数是否与外部指标冲突；
- 产生失败案例和可视化对照。

历史 Pilot 中出现的结构性 partial/deadlock 场景必须和真正的可解场景分开统计，不能
把所有失败简单归因于权重不好。

## 7. 机器学习目标

### 7.1 第一阶段算法

推荐使用带合法动作 mask 的 PPO。原因是动作离散、状态固定为二维多通道图、动作约束
明确，而且 PPO 便于获得策略概率和训练诊断信息。

第一版网络采用小型 CNN：输入二维状态张量，输出所有格子的 action logits 和一个 value
估计。训练稳定后再考虑图神经网络；GNN 是未来曲面图迁移的候选，不是当前第一步。

### 7.2 奖励

奖励必须优先保证完成和安全，再优化路径效率。建议拆成可审计的组件：

```text
每次 cut              - transfer_cost
前沿张力风险          - tension_cost
器官局部能量风险      - organ_energy_cost
血管应变风险          - vessel_strain_cost
成功完成              + completion_bonus
死锁或超步数          - failure_penalty
```

第一版不要把所有指标压成不可解释的单一分数。训练日志必须同时保存每个奖励分量，避免
出现总 reward 上升但张力或完成率恶化的 reward hacking。

推荐先把血管和器官风险作为硬约束或强惩罚进行小规模实验，再决定是否让模型学习风险
权衡。不能仅凭距离血管远近声称已经优化了临床安全。

### 7.3 外部评价

最终评价不直接使用训练 reward，而使用冻结的外部指标：

- 完成率和合法动作率；
- 总 transfer 数和 transfer overhead；
- 总移动步数和 episode 长度；
- 平均及最差 10% 的前沿张力、器官能量和血管应变；
- 最大风险峰值；
- release 规则正确率；
- 规则基线和 RL 的差值及置信区间。

训练集、验证集和测试集必须按随机种子或场景种子划分，不能让同一个几何场景的变体
同时出现在训练和测试中。

### 7.4 7×7 受约束风险评价与泛化顺序

为避免在已有结果后挑选“更有利”的数字，后续候选在训练前须固定下列评价规则。它们首先
应用于已训练 Spatial-v3 与冻结基线的 7×7 回放；这一步只重算和审计评价，**不更新模型参数**。

1. **硬约束**：Test 的完成率、合法动作率和 release 正确率均为 1.000。
2. **效率非劣**：相对 S 形优先/release 和规则规划器，Test 的 transfer overhead 不超过各自
   基线的 110%；同时报告逐场景配对差值及其 bootstrap 置信区间。
3. **风险主终点**：仅在前两项满足后，比较相对规则规划器的血管应变最差 10% 均值（CVaR）和
   全程累计血管应变；方向为更低。两项都必须以逐场景配对置信区间报告，不能只比较总体均值。
4. **完整报告而非总分**：同步报告前沿张力和器官能量的最差 10% 均值、风险阈值以上的步数比例、
   最大风险峰值、transfer、episode 长度及 Pareto 胜/平/负比例。未经校准的力学代理量不得
   合成为临床风险分数，也不得据此声称临床安全获益。

该框架不是新的 7×7 网络，也不是把一个新 metric 直接写入训练奖励。它将现有“路径连续性”
评价改为“在路径效率不明显退化的条件下，是否降低血管牵拉代理风险”的可检验命题。只有在
7×7 固定尺寸上完成此评价后，才进入下一轮 **同尺寸、不同布局** 的泛化训练：扩大训练场景池、
固定教师筛选规则、至少三个随机 seed，并在独立 Validation 集选模。该阶段仍不验证 9×9 或
可变尺寸泛化；尺寸泛化须在其后单独设计训练和测试集。

### 7.5 可变尺寸目标：最大 30×40 网格

最终二维研究目标不是固定 7×7 或 50×50，而是最大为 **30×40** 的网格和任意较小的
不规则有效边界。一个网格单元固定对应一次 **4 mm** 的超声刀切除动作；因此最大网格对应
约 $120\,\mathrm{mm} \times 160\,\mathrm{mm}$ 的离散切除范围。病例重采样分辨率必须随
场景元数据记录，训练和测试中不得任意改变该离散尺度。

因此，7×7 策略只承担环境、奖励、指标和局部切除规律的验证作用。当前固定 49 动作头的
Spatial-v3 不能直接部署或直接扩展到 30×40；后续主策略须改为可变尺寸空间策略：

- 使用最大 30×40 的零填充观测和 `valid_cell_mask`，保留真实长宽比，不把不同大小的病例缩放成
  同一个形状；
- 使用全卷积的逐格 action-logit 图和动态 action mask，而不是 49 维或任何依赖固定格数的动作头；
- 在 observation 中显式加入当前位置到已切区域的可达/transfer-distance 图，帮助策略处理长程
  回穿代价；
- 继续复用底层 `PlanarResectionEnv` 的 cut、transfer、release、力学和 replay 语义，但增加
  30×40 局部坐标与底层 50×50 规范画布之间的适配层；
- 只有在新策略以 7×7 训练、推理均通过回归后，才允许将其权重作为更大尺寸课程的初始化。

训练按尺寸和不规则度渐进，但始终混入已通过阶段的较小场景以避免遗忘：

| 阶段 | 训练范围 | 目的 | 不用于宣称的能力 |
| --- | --- | --- | --- |
| A | 5–8 × 5–8，含 7×7 | 验证可变尺寸策略、动作映射和局部风险目标 | 大尺寸泛化 |
| B | 9–16 × 9–16，轻度不规则边界 | 学习跨局部区域的连续切除 | 最大尺寸能力 |
| C | 17–24 × 17–32，多血管和凹形域 | 学习中程 transfer 与 release 组合 | 30×40 极端边界 |
| D | 至多 30×40，高不规则边界、狭窄通道和多组件血管 | 目标尺寸内的训练与验证 | 临床有效性 |

每个阶段的 Test 必须保留未参与训练的尺寸、长宽比、边界形状和血管组合；最终 30×40 Test
不得参与任何奖励、网络或早停选择。最长 episode 将从约 49 步增至最多 1,200 步，先保持逐格
动作以保证与既有事件语义可比；若训练吞吐或长程 credit assignment 成为瓶颈，再单独验证宏动作
展开后与逐格 replay 完全一致，不能直接改变指标定义。

## 8. 数据和实验划分

### 8.1 场景生成

每个场景记录完整 JSON：

- seed、行列数和域单元；
- 血管连通块及 release 参数；
- 起点；
- 厚度场和力学参数；
- 环境版本和随机数生成器版本。

场景应覆盖规则场景、非矩形场景、狭窄通道、多血管块、深直线切口和不可解压力场景。

### 8.2 推荐划分

| split | 用途 |
| --- | --- |
| Pilot | 检查环境、奖励和基线，不用于最终结论 |
| Train | PPO 参数更新 |
| Validation | 选择 checkpoint、奖励系数和停止点 |
| Test | 最终一次性报告 |
| Stress test | 专门测试死锁、狭窄域、长切口和高张力 |

初始规模可采用 Train 500、Validation 150、Test 200，并保存每个 split 的固定 seed。
若环境语义或奖励发生改变，必须重新生成并重新编号场景集。

## 9. 实施顺序

### 阶段 0–4：已完成的二维基础

- 环境契约、action mask、release/deadlock/终止测试和 JSON replay 已完成；
- 逐行/S 形基线、规则规划器、冻结场景池、统一外部指标与固定场景对照已完成；
- 5×5、7×7 toy 验证、zero-tension、深直线切口与对称性回归检查已纳入当前二维基础；
- Maskable PPO 已在局部 7×7 小型 CNN 视图上完成训练，并保存 checkpoint、配置、seed、
  环境版本及训练曲线；
- 已对冻结 Test/Stress 执行 PPO、S 形、行列优先和规则规划器的配对对照。当前基线和
  策略结果以第 3.3 节登记为准，历史 Pilot 不可覆盖该登记。

后续二维实验应围绕已冻结的评价门开展奖励组件、张力状态、血管状态与多随机种子消融；
在引入新的尺寸前，不得将 7×7 结果外推为尺寸泛化。可变尺寸策略的实现和课程以第 7.5 节为准。

### 阶段 5：曲面迁移决策

只有在二维 PPO 满足以下条件后才迁移曲面：

- 合法动作率为 100%；
- 完成率不低于规则基线；
- 至少一个主要外部指标稳定改善，其他指标没有明显恶化；
- 对场景尺寸、形状、血管布局和随机种子具有稳定性；
- 医生或研究人员能够解释策略的典型行为。

## 10. 环境和 GPU 准备

训练前在实际 Conda 环境中记录：

- Python、PyTorch、Gymnasium、Stable-Baselines3 和 sb3-contrib 版本；
- CUDA 是否可见、GPU 型号和显存；
- 单环境和并行环境的 step 吞吐；
- CPU 与 GPU 的时间占比。

GPU 主要加速策略网络训练。随机域生成、合法 mask、transfer 搜索和 2.5D 求解通常仍
依赖 CPU，因此不能仅凭 CUDA 可用就假设整体训练按比例加速。

## 11. 停止条件和风险

出现以下情况时停止扩大训练规模，先回到环境或奖励设计：

- reward 上升但外部指标下降；
- RL 通过绕开血管或延迟 release 获得更高分；
- 环境出现与 planner 不一致的事件；
- 测试集性能明显低于验证集；
- 深直线切口、对称场景或零预应变测试失败；
- 模型只在固定网格尺寸上有效。
